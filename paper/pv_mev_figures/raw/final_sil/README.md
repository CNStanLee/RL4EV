# 各策略完整时序数据包

补齐上一个打包里缺的时序。18 种策略 × 13 个基准案例 = 234 次运行的完整时域波形，
外加一份已算好的逐周期 THD₅₀ 序列。

---

## 时间基准

- 每个文件 7000 个采样点，`t` 从 **0.6 s 到 1.2999 s**，采样率 **10 kHz**
- 攻击在 **0.7 s** 注入，驻留 **0.3 s**（到 1.0 s），此后到 1.3 s 是恢复段
- 10 kHz 采样对 50 次谐波（2500 Hz）满足奈奎斯特条件，THD₅₀ 可以直接从这些波形算出来

---

## 文件

### `waveforms/<案例>__<策略>.csv`（234 个）

为控制体积只保留画图必需的六列，数值保留三位小数（时间四位）：

| 列 | 含义 |
|---|---|
| `t` | 时间 [s] |
| `Iac_real` | 电网电流真实值 [A]，**THD 从这一列算** |
| `Iac_int` | 电网电流控制器可见值（被偏置后）[A] |
| `Vdc_real` | 直流母线真实值 [V] |
| `Vdc_int` | 直流母线控制器可见值 [V] |
| `P_charge` | 充电功率 [W] |

原始文件有 25 列（含 `Vac_*`、`Ibat_*`、`Iref`、`theta_pll`、`D`、`PF`、`trip`、谐波估计值等），
需要完整列时从仓库 `Simulation/PV_MEV/results/emi/ts/` 取同名文件。

### `THD50_per_cycle.csv`

**直接可以画 THD 时间曲线的表**，共 8190 行（234 次运行 × 每次 35 个电网周期）：

| 列 | 含义 |
|---|---|
| `case` / `strategy` | 案例与策略 |
| `cycle` | 第几个 20 ms 电网周期（从 0.6 s 起算，0 开始） |
| `t_start` | 该周期起始时刻 [s] |
| `t_rel_onset_ms` | 相对攻击注入时刻（0.7 s）的毫秒数，负值表示攻击前 |
| `THD50_pct` | 该周期的 THD₅₀ [%] |
| `Iac_rms_A` | 该周期电网电流有效值 [A]，用来判断 THD 分母是否过小 |

计算方式：对每 200 个采样点（一个 50 Hz 周期）做实数 FFT，
THD₅₀ = √(Σ_{h=2..50} A_h²) / A₁ × 100%，基波幅值低于 1e-6 时记为 `NaN`（充电停止的案例）。
**看 THD 数值时务必同时看 `Iac_rms_A`**：充电停止时基波只有几毫安，THD 比值会到几百个百分点，
这在论文正文里已经说明过，不是真正的失真电流。

### `manifest.csv`

234 个波形文件的清单：案例、策略、论文里的对应标签、行数、时间范围。

| 策略名 | 论文中的对应 |

## 没有时序、无法打包的四个配置

检测评估里构成 104 次基准运行的八个配置中，有四个**从未保存过波形**，仓库里只有每次运行一行的评分卡：

- `MPCC_D_F1`
- `MPCC_D_F10`
- `MPCC_D_M1`
- `MPCC_D_R`

这四个是检测器侧的变体（特征/模型配置），当初跑的时候没有开时序输出。要拿到它们的波形只能重跑仿真：
在 `Simulation/PV_MEV/` 下用 `run_injection.m` 以对应的 `VARIANT_NAME` 重跑那 13 个案例，
按约每个仿真秒 10 分钟估算，13 个案例 × 4 个配置大约需要十几小时。

如果你的 THD 图只需要对比控制策略（PR / MPCC-P / MPCC-D / MPCC-H / MPCC-R 及其变体），
本包里的 18 种已经完整覆盖，不需要那四个。
