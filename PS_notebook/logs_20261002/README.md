# 2026-10-02 板卡功耗（PMBus）

`power_20261002.csv` 是 `measure_power.sh /home/xilinx/mpcc_r <csv> 3` 的原始输出：每 0.25 s 读一次 ZCU104 各电源轨功率，
三轮，每轮四个状态各 20 s（每状态共 234 个样本）。比特流均为仓库重建版本（`mpcc_hil.bit` 仅控制器，`mpcc_r.bit` 完整四核）。
“运行”对仅控制器设计是 20 kHz 占空比循环（`pwr_loop`），对完整设计是三任务实时并发重放（`run_rt_sched.sh`）。

| 状态（tag） | 12 V 输入 [W] | 核心轨 INT [W] |
|---|---|---|
| `ctrl_only_idle` | 10.63 | 1.50 |
| `ctrl_only_active` | 10.75 | 1.50 |
| `full_idle` | 10.97 | 1.75 |
| `full_active` | 11.35 | 2.00 |

完整设计运行时比仅控制器设计多 0.61 W（12 V 输入，5.6 %），核心轨多 0.50 W。INT 轨读数分辨率为 0.25 W。
三轮之间各状态的 12 V 均值相差不超过 0.02 W。测功耗时的三次 30 s 实时重放（各 600 001 次控制释放）均无迟到。
